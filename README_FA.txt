Fast File Manager

نسخه پایه پروژه برای Mgit / GitHub Actions.

قابلیت‌های ثبت‌شده این نسخه:
- نمایش فایل و پوشه
- انتخاب تکی و گروهی
- Tag تکی و گروهی
- نامگذاری پیشرفته و گروهی با پیش‌نمایش و شماره‌گذاری
- Favorites
- Library: New Files و Big Files
- Search و Go to Path
- Sort: Name, Size, Date, Type, Tag و گزینه‌های Title/Parts
- Properties و Copy اطلاعات خصوصیات
- Show Hidden Items
- Delete Empty Folders
- USB / HDD از طریق Android Storage Access Framework
- File Picker برای انتخاب فایل از برنامه‌های دیگر
- آیکون نوع فایل برای فرمت‌های متداول از جمله APK/XAPK/APKS/AAB
- نوار بالایی با دکمه‌های بزرگ و قابل پیمایش

نکته: این نسخه ساختار و رابط و قابلیت‌های مدیریتی را آماده می‌کند. عملیات واقعی Copy/Move/Compress/Extract باید در مرحله بعد با پیاده‌سازی امن و سازگار با Storage Access Framework کامل شود.

ساخت APK در GitHub Actions با workflow موجود انجام می‌شود.
